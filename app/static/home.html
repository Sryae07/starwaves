FEATURES

它能做什么

🛰️

多游戏合并看板

星铁、鸣潮、绝区零同屏展示：等级、活跃天数、成就、资源、角色图鉴一页尽览，看板内「➕ 接入游戏」可直接登记新游戏。

👤

账号与档案分离

手机验证码注册 / 密码登录，用户名即档案名（不填自动生成「用户＋随机编号」），多账号互不干扰，各自一条分享链接。

📡

官方资讯聚合

米游社公告、库洛官网新闻实时聚合到一个信息流，每 5 分钟自动刷新。

⏳

体力回满倒计时

开拓力 / 结晶波片 / 电量实时推算回满时间，开游戏前先瞄一眼。

📸

截图 OCR 识别

上传游戏截图自动识别数字，先核对再入库，误差可控。

🔗

UID 官方式接入

星铁输入 UID 即拉取米游社战绩：角色柜台（命座/命途）、忘却之庭·虚构叙事·末日幻影·模拟宇宙进度全同步；鸣潮用本地导出 JSON / OCR。

📈

体力历史曲线

最近 30 条快照自动成图，回看自己的清体力节奏。

🚀

一键启动游戏

手机或电脑点一下，电脑直接拉起星铁 / 鸣潮——提权自动完成，人在哪都能启动。

ABOUT

关于本项目

为什么做这个

几款游戏的数据分散在不同客户端里，每次想看体力、成就还得切游戏。 Sryaestart 把它们汇总成一张"游戏名片"：自己看、发朋友看，都行。 所有数据归你本人所有，存于你自己的数据库；账号密码仅存散列摘要，手机号对外仅脱敏展示。

数据来源与风险（实话实说）

  • · 鸣潮无官方开放接口：依赖本地工具导出 JSON 或截图 OCR，无法全自动实时同步
  • · 米游社接口为社区逆向协议：存在失效与风控风险，Cookie 仅保存在本机 .env
  • · OCR 存在识别误差：设计为"先识别、人工核对、再入库"两段式流程
